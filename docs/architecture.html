⑦ 建议学习 / 补全路线

按依赖顺序推进，每步都能对照上面的分层图复用同一套请求模式。

1

落地 Pinia：用户 Store

把 token / 用户信息从散落的 localStorage 收拢到 useUserStore；在 Mine 页调用 removeToken 做退出。

2

商品详情页

新建路由与 View；首页 / 搜索结果卡片点击传入 prodId，补 API + 类型。

3

分类页 CategoryView

从空壳做成左侧分类 + 右侧商品；复用 get() 模式。

4

购物车 Store + CartView

加购、改数量、结算；这是练习 Pinia 跨页共享状态的最佳场景。

5

强化 request 拦截器

统一处理业务 success / 401 清 token 跳登录，减少每个页面重复判断。
